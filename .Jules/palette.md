## 2026-09-12 - Sticky Header Navigation & Accessibility Landmark Patterns
**Learning:** In single-page applications with sticky headers (e.g. 80px / h-20 header), anchor navigation (such as skip links or section navigation links) can jump to content behind the fixed header without proper scroll offset configuration. Pairing a hidden "Skip to main content" link with a `<main id="main-content" tabIndex={-1}>` landmark, `scroll-pt-20`, and `motion-safe:scroll-smooth` on the `html` element ensures visible, unobscured keyboard navigation and seamless screen reader focus management.
**Action:** Always combine a skip-to-content link targeting `<main tabIndex={-1}>` with `scroll-pt-*` matching sticky header height and visible focus rings (`focus-visible:ring-gold`) on navigation items.

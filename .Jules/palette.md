## 2026-07-29 - Establish Semantic Foundation and Focus Outlines
**Learning:** In single-page applications with sticky headers (such as the 80px h-20 navigation header), keyboard focus and anchor links can be easily obscured. Combining a "Skip to Content" link targeting a `<main>` landmark element (using `tabIndex={-1}` and `className="outline-none"`) with a scroll-padding top on the `html` element ensures smooth, non-obscured keyboard navigation. Additionally, standardized focus visible styles (`focus-visible:ring-2 focus-visible:ring-gold`) provide clear visual tracking for keyboard-only users.
**Action:** Always implement a skip link as the first focusable element, use proper `<main>` sibling to footer landmark structure, and configure `scroll-padding-top` and standardized `focus-visible` styles on global elements within Tailwind `@layer base`.

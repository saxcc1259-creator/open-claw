## 2026-08-10 - Semantic Foundation and Accessible Mobile Navigation
**Learning:** Combining CSS transitions (opacity, visibility, max-height) in single-page apps is the most effective way to handle accessible mobile menus without conditional React rendering. Transitioning elements to `visibility: hidden` prevents keyboard focus (`Tab`) and screen reader access of navigation links when the menu is collapsed. Additionally, applying `scroll-padding-top` on the `html` element prevents sticky headers from obscuring sections targeted by skip-to-content and page anchor links.
**Action:** Always combine opacity transitions with `visibility: hidden` (or Tailwind's `invisible`) for collapsed navigation drawers, and ensure `html` has `scroll-padding-top` matching the sticky header's exact height for flawless scroll-to anchor navigation.

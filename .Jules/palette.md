## 2026-07-27 - Semantic Foundation Pattern
**Learning:** For single-page applications with sticky headers (such as this 80px sticky navbar), implementing a "Skip to Content" link targeting a `<main>` landmark with a proper focus-shift configuration (`tabIndex={-1}` and `className="outline-none"`) combined with scroll offsets (`scroll-padding-top`) and `motion-safe:scroll-smooth` on the HTML element provides a seamless and accessible keyboard/screen reader navigation experience without visual layout regressions or sticky header overlap.
**Action:** Always combine a 'Skip to Content' link targeting a `<main>` landmark with `scroll-pt-20` (80px header height matching `h-20`) in Tailwind or CSS `@layer base` to ensure high accessibility and elegant keyboard navigation flow.

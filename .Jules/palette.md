## 2025-02-12 - Sticky Header Anchor Navigation & Accessibility
**Learning:** For single-page applications with a sticky header, standard anchor links cause the header to overlap the target heading. Combining `scroll-margin-top` on section targets with `motion-safe:scroll-smooth` on the HTML element provides a polished, non-obscured navigation experience. Additionally, a "Skip to Content" link is essential for keyboard users to bypass repetitive navigation, but it must target a `<main>` landmark with `tabIndex={-1}` and `outline-none` to manage focus programmatically without creating unintentional focus rings.
**Action:** Always implement `scroll-mt-[header-height]` on section IDs and provide a high-visibility skip-link targeting a correctly configured `<main>` landmark in SPA layouts.

## 2026-11-06 - Semantic Foundation and Sticky Header Scroll Coordination

**Learning:** In single-page landing pages featuring a fixed/sticky header (such as an 80px / 5rem header), keyboard navigation and anchor jumps often cause targeted elements to be obscured beneath the navigation bar. Additionally, screen reader and keyboard-only users need an immediate skip-to-content mechanism targeting a `<main>` landmark with `tabIndex={-1}` and `outline-none` so programmatic focus shifts without introducing unsightly visual rings around the main container. Furthermore, pairing `scroll-padding-top: 5rem` with `motion-safe:scroll-smooth` on the `html` element ensures both manual clicks and skip navigation maintain proper spacing beneath sticky headers without jarring motion for users who prefer reduced motion.

**Action:** Whenever building or enhancing single-page sites with sticky navigation, implement a 'Skip to Content' link as the first focusable element, wrap core page content in `<main id="main-content" tabIndex={-1} className="outline-none">` alongside sibling landmarks, set `scroll-padding-top` equal to header height with `motion-safe:scroll-smooth` in `@layer base`, and ensure mobile toggles properly manage `aria-expanded` and `aria-controls`.

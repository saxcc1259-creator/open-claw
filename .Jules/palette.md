## 2026-11-04 - Sticky Header Anchor Navigation and Skip Links
**Learning:** In single-page landing pages with fixed/sticky headers (such as an 80px `h-20` navbar), keyboard focus and anchor navigation can cause headings or focused content to be partially obscured behind the header bar unless global scroll padding (`scroll-pt-20` on `html`) and `scroll-mt-20` offsets are applied. Combining an accessible 'Skip to main content' link that targets `<main id="main-content" tabIndex={-1} className="outline-none">` with dynamic ARIA attributes on mobile navigation toggles establishes a robust, accessible semantic baseline without layout shifts.
**Action:** When implementing sticky navigation headers in future micro-UX improvements, pair the sticky header with `html { @apply motion-safe:scroll-smooth; scroll-padding-top: 5rem; }`, anchor the skip link directly to `<main id="main-content" tabIndex={-1} className="outline-none">`, and ensure mobile hamburger buttons communicate `aria-expanded` and `aria-controls` states.

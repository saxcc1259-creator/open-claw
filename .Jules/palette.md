## 2026-08-11 - Semantic Foundation & Smooth Navigation
**Learning:** Combining a keyboard-accessible skip link with a `<main>` landmark element utilizing `tabIndex={-1}` and `outline-none` provides seamless, screen-reader-friendly layout jumps. In applications with sticky navigation headers, integrating `scroll-padding-top` (scroll-pt) matching the header height ensures anchor jumps do not hide targeted section headings beneath the sticky bar, and keeping landmarks properly structured enhances screen-reader experience.
**Action:** Always wrap primary content in a `<main id="main-content" tabIndex={-1} className="outline-none">` block as sibling to header/footer, add skip link as first focusable element, and add scroll offset configuration (e.g., `scroll-pt-20` or `@layer base { html { scroll-padding-top: 5rem; } }`) to handle sticky nav overlaps cleanly.

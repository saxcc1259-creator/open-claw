## 2026-08-06 - Semantic Foundation Coordination for Sticky Headers
**Learning:** For single-page applications with sticky headers (e.g., height of 80px), merely shifting programmatic focus to a `<main>` container via a "Skip to Content" link is insufficient if anchor scroll behavior obscures content. Combining a skip link with target `tabIndex={-1}` and outline suppression works perfectly only when paired with `@apply motion-safe:scroll-smooth scroll-pt-20` on the root HTML element.
**Action:** When designing a single-page app or sticky header navigation, always bundle the skip link, semantic `<main>` landmark with `tabIndex={-1}`, offset scroll padding (`scroll-pt-[header-height]`), and visible focus ring styling as a single, cohesive accessibility foundation to ensure a flawless experience for keyboard and screen-reader users alike.

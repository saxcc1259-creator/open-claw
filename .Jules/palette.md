## 2026-07-31 - Semantic Foundation & Navigation UX
**Learning:** Single-page applications with sticky headers and responsive mobile menus require cohesive, coordinated accessibility (a11y) solutions to prevent poor user experiences. For instance, without scroll-padding-top on the HTML element, skip links and anchor navigations scroll headings underneath the sticky nav, obscuring them. Additionally, using simple conditional rendering for mobile menus prevents entry/exit transitions. If transitions are added, they must always pair the closed state with `visibility: hidden` (Tailwind's `invisible` utility) so that keyboard and screen-reader users cannot focus on hidden, off-screen interactive elements.
**Action:** Always combine a 'Skip to Content' link targeting a `<main id="main-content" tabIndex={-1} className="outline-none">` landmark with scroll-padding (e.g. `scroll-pt-20` for a h-20 header) and `motion-safe:scroll-smooth`. For responsive navigation, pair smooth CSS-based transitions (using max-height or opacity) with the `invisible` utility in the closed state, and set appropriate dynamic aria attributes (`aria-expanded`, `aria-controls`, `aria-label`) on the toggle trigger.

## 2026-07-18 - Semantic Foundation Implementation
**Learning:** Single Page Applications with sticky navigation headers benefit significantly from a combined approach of a "Skip to Content" link targeting a `<main>` landmark with a proper `tabIndex={-1}`, coupled with `@apply motion-safe:scroll-smooth scroll-pt-20` on the HTML base element and standard custom focus rings (`focus-visible:ring-2 focus-visible:ring-gold focus-visible:ring-offset-2`). This guarantees both smooth keyboard navigation and visual alignment without elements being obscured.
**Action:** When working on real estate or portfolio style landing pages with sticky headers, always build out this 'Semantic Foundation' standard layout first, ensuring the skip-to-content target is wrapped around main page sections.

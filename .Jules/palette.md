## 2026-08-02 - Establishing Semantic Accessibility Foundations
**Learning:** Single-page real estate applications with sticky headers often present major keyboard navigation hurdles. Without a 'Skip to Content' link, keyboard and screen reader users must tab through multiple header links on every single page load. Additionally, using standard fragment identifier anchor links to sections can cause the targeted section heading to be obscured by the sticky header if no appropriate scroll padding or offset is applied to the root viewport. Wrapping sections under a proper `<main>` landmark element is essential for screen reader navigation context, and keeping the `<main>` and `<footer>` elements as direct sibling landmarks conforms to valid semantic nesting standards.
**Action:** Always implement a 'Skip to Content' link targeting a `<main>` landmark with `tabIndex={-1}` and `outline-none` class (to prevent visual layout shifts while ensuring correct focus shifts). Pair this with global `motion-safe:scroll-smooth` and appropriate `scroll-pt-[header-height]` (e.g. `scroll-pt-20` for an 80px sticky header) in the CSS to guarantee clean section targeting without blocking headings.

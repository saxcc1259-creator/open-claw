## 2026-08-12 - Reusable Skip Link and Scroll Offset Pattern
**Learning:** Single-page applications utilizing sticky headers often suffer from focus truncation or layout shift when users navigate via keyboard or skip links. If proper scroll offset padding is not paired with a hidden-until-focused 'Skip to Content' link targeting a `<main>` landmark with a proper tabIndex, keyboard focus shifts programmatically but the visual view either obscures the target or fails to shift smooth scroll transitions gracefully.
**Action:** Always combine a 'Skip to Content' link targeting a `<main id="main-content" tabIndex={-1} className="outline-none">` element with `motion-safe:scroll-smooth` and `scroll-pt-[header-height]` (such as `scroll-pt-20` for an 80px sticky header) applied in the CSS base layer, ensuring seamless, non-obscured keyboard navigation.

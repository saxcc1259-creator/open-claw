## 2026-11-07 - Semantic Foundation Pattern for Single-Page Sites with Sticky Navigation
**Learning:** Single-page marketing websites with a sticky navigation bar (such as `h-20` / 80px) frequently trap keyboard and screen-reader users into tabbing through all header links on every navigation, while standard anchor links cause heading content to be obscured beneath the fixed header. Additionally, wrapping the whole page in `<main>` without excluding `<nav>` and `<footer>` violates semantic landmark hierarchy.
**Action:** Always implement a dedicated "Skip to main content" link as the first focusable element targeting `<main id="main-content" tabIndex={-1} className="outline-none">` positioned above the header stacking context (`focus:z-50` vs header `z-40`). Pair this with `html { scroll-padding-top: [header-height]; @apply motion-safe:scroll-smooth; }` so that anchor jumps and skip-links never obscure section headings.
